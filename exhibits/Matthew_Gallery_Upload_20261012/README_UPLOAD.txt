馬太展覽上傳包（2026-10-12）

本包是 virtualgallery.store 既有網站的更新檔，不是完整原網站。

上傳方法：
1. 解壓縮本 ZIP。
2. 將 index.html、matthew.html、exhibits、shared 放到網站 repository 根目錄，依原路徑合併。
3. 保留原網站的其他展廳、assets 與 360view；不要清空原目錄。
4. 本包 index.html 保留下載當時的七座原展廳，新增馬太展覽入口，並加入首頁中英與 MP3 選項。覆寫前可另存原 index.html。
5. GitHub Desktop：檢查變更 → Commit → Push，等待網站發布。

完成後網址：
https://virtualgallery.store/matthew.html
https://virtualgallery.store/exhibits/matthew/gallery.html

功能與資料：
56 幅画作、28 章經文及英文真人錄音、中英操作介面、蜂鳥飛行、10 秒閒置自動飛行。
四首 MP3 放在 shared/music，初始音量 1/3。馬太與首頁使用同一份音樂。
原有其他展廳的 MP3 面板需再用 V10 管理工具「套用至全部展廳與首頁」後匯出更新包。

V10 管理：
載入合併後的網站根目錄即可辨識馬太展覽，可預覽、設定封面與保存面板參數。
管理工具不要上傳到公開網站。

本機啟動後可使用匯入與佈展功能；上傳網域後為欣賞版。
本包通過程式與檔案路徑檢查，尚未在使用者瀏覽器實測播放。
