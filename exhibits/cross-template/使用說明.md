# 十字形展廳可重用模板 v1

第一階段：共用十字形展廳程式，分離展名、作品、預設佈展與儲存資料。保留原有 30 個掛畫位置、換圖、Excel 資料匯入、燈光、環景、導覽、平面圖、物件、場景拍照與分享功能。

## 開啟 GitHub 上傳版

上傳後，以網站 /exhibits/cross-template/ 開啟工作台，或由總入口第 7 張卡片進入示範展廳。
桌機離線預覽請使用之前提供的展廳桌機預覽面板，讀取完整網站資料夾。
不要直接雙擊 HTML；模組與設定需透過 HTTP 服務載入。
此網站版不包含本機 Python 啟動程式。

## 新展廳：不用修改共用程式

在工作台填入展廳 ID、展名、副標、作者、光線與環景，按「下載新展廳 ZIP」。完整解壓縮新 ZIP，再使用桌機預覽工具開啟，或上傳網站。新的首頁有進入展廳按鈕。

每個展廳請使用不同 ID，例如 chino-2026、photo-autumn；相同 ID 會共用同一網站下的本機草稿。新模板不會讀取舊版 stl-gallery 的圖片或草稿，也不會刪除它們。

兩個預設範例：cross-demo（日照）與 chino-demo（黃昏）。共同讀取 app 與 assets，但儲存互相隔離。

## 修改設定

| 檔案 | 修改內容 |
| --- | --- |
| projects/展廳ID/gallery.json | 展名、預設光線、環景、牆面、屋頂、燈光強度與畫質 |
| projects/展廳ID/artworks.json | 01 至 30 的作品名稱、作者、年份、描述、畫框及圖片路徑 |
| projects/展廳ID/layout.json | 預設桌椅與掛畫位置；slots 空陣列表示自動產生原來的 30 個位置 |
| app/ | 共用程式，正常新增展廳不用修改 |
| assets/ | 共用圖片與 Three.js |
| 360view/ | 共用環景圖片、縮圖與清單 |

圖片路徑相對於 gallery.json，例如 ../../assets/xxx.webp。可將新圖片放入 assets 並更新作品的 image 欄位；也可直接在展廳內換圖，再匯出展示 ZIP。

設定檔修改後重新載入；既有瀏覽器草稿可能覆蓋部分預設設定。若要建立全新展覽，使用新 ID；如要回復作品，使用展廳原有重設功能。不要直接刪除其他展廳的瀏覽器資料。

## 觀看與編輯

- 原有控制台、W/A/D/下方向鍵移動、S 場景拍照、M 平面圖繼續使用。
- 最新三張場景照片可選一張作封面。
- 預設作品資料包含原版範例內容；使用者需自行確認作者與作品資訊。
- 修改作品或佈展儲存在目前瀏覽器，不會自動寫回 JSON 或更新 GitHub。

## 分享與上傳

「分享檔」改為匯出完整展示 ZIP：包含唯讀展示首頁、封面 JPG、模組、圖片與環景。使用 ZIP 內的 index.html 作為入口；HTML 需配合 app、assets、360view，不能單獨傳送。

上傳範例：將解壓縮內容放到既有網站的 exhibits/chino-2026/ 目錄，以 exhibits/chino-2026/index.html 進入，再手動在原總入口加入連結。這樣不會覆蓋目前網站的 index.html。工具不會自動部署。

自行新增圖片或程式檔案後，也要把該路徑加入 template-manifest.json 的 files，否則完整匯出 ZIP 不會收錄它。缺少清單內的檔案時，打包會明確停止。

## 第一版範圍與驗證限制

這版仍使用固定十字形輪廓與 30 幅作品。尺寸、門口、屋頂、碰撞與部分場景功能仍在共用 engine-cross.js 內，尚未拆成可任意換造型的引擎。新的白宮或郵輪空間仍需後續建構模組。

已驗證設定、掛畫位置、資料隔離、資源引用與 ZIP 匯出；未在此環境進行 Windows/手機實機 WebGL 檢查，請先使用桌機預覽確認，再上傳。
