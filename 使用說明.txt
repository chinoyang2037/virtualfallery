Virtual Gallery 網站加速版

此套件供 GitHub Pages 網站上傳，不是單一離線 HTML。

上傳方式：
1. 解壓縮 ZIP。
2. 將 index.html、五個展廳 HTML、五張 JPG 與 assets 資料夾上傳到原本網站的根目錄，取代同名檔案。
3. assets 內全部檔案都必須一起上傳；不要只上傳 HTML 或直接上傳 ZIP。
4. 等 GitHub Pages 部署完成後，用 Ctrl+F5 重新整理並測試五個展廳。
5. 原本的展廳網址與檔名皆保留。建議先保留原檔備份，或使用 GitHub 提交歷史復原。

修改內容：
內嵌圖片分离為外部 WebP，保留原始解析度，使用有損壓縮。重複圖片與共用程式以相同檔案快取。
工業風三版與白宮加入「渲染畫質」選單，位於控制台最上方，預設標準，可切換高畫質。
La Galerie 保留原有自動解析度設定。首頁與展廳操作程式保持原本功能。
此版仍會在啟動時載入畫作，尚未改為依觀看距離延遲載入。

驗證：全部外部資源路徑、圖片解碼與 JavaScript 語法已檢查。
此環境無法取得瀏覽器執行檔，因此尚未完成實際 WebGL 進場與操作測試；上傳前可先用本機 HTTP 伺服器測試。
本機測試：在此資料夾開啟終端機，執行 python -m http.server 8000，再用 Chrome 開啟 http://localhost:8000/。
請勿以 file:// 直接開啟作為驗證；瀏覽器可能限制外部貼圖。
實際加速幅度受網路、GitHub Pages 快取與顯示卡影響，不保證固定秒數。
